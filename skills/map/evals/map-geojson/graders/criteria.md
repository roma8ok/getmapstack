The answer passes when all of these hold.

- The page is reachable over HTTP from the running container, and the answer gives the
  URL. A file written to disk and nothing more is a failure.
- The view is derived from the extent of the features, not from a zoom chosen in
  advance.
- The template is used as shipped: colours and labels, if any were wanted, are set as
  feature properties rather than by editing the page.
